# A · 知识库与检索

## 一、模块位置

链路：用户提问 → **检索** → 生成 → 工具 → 安全校验 → 输出

本模块把用户问题转成若干段带出处的资料，交给 B 填进提示词。

- 输入：用户问题（字符串）
- 输出：证据列表（原文片段 + 出处）

检索内容不对，后面几步补不回来。这个模块的效果决定系统上限。



## 二、接口

字段按实际数据集增删，最低要求是每条证据都带原文和出处。

`retrieve(问题, k=5)` 返回：

```json
{
  "query": "二甲双胍常见副作用有哪些",
  "evidence": [
    {
      "chunk_id": "metformin_leaflet_c42_001",
      "text": "常见不良反应包括腹泻、恶心、腹胀……",
      "source": "盐酸二甲双胍片说明书",
      "section": "4.2 不良反应",
      "page": 3,
      "year": 2024,
      "score": 0.83
    }
  ]
}
```

- 查不到内容时返回 `"evidence": []`
- 不要把不相关片段硬塞进来，宁可返回空

## 三、知识库技术路线

### 1. 切分

| 做法 | 要求 |
| --- | --- |
| 切分依据 | 按文档自身标题层级切：正则匹配 `第X章` `第X节` `一、` `（一）` |
| 块大小 | 300–600 字，相邻块重叠 50–100 字 |
| 表格 | 单独成块，转成 markdown 表格或「字段: 值」文本，不要切散 |
| 元数据 | 每块附带 source / section / page / year |
| 禁止 | 按固定字数硬切，会把句子和表格切断 |

### 2. 索引

两条索引同时建：

- **向量索引**：用 embedding 模型把每块转成向量，用于语义相似
- **关键词索引**：中文分词（jieba）后建 BM25，用于术语精确匹配

医学问题经常是术语和药名，纯向量容易漏，关键词索引不能省。

### 3. 检索（四条路线，按投入递增）

| 路线 | 做法 | 效果 | 建议 |
| --- | --- | --- | --- |
| R1 纯向量 | 只查向量索引 | 一般 | 不推荐单独用 |
| R2 混合检索 | 向量 + BM25，用 RRF 融合两路结果 | 明显好于 R1 | **起点，必做** |
| R3 混合 + 重排 | 混合检索取 top50，用重排模型取 top5 | 最好 | **目标状态** |
| R4 加查询改写 | HyDE、多查询扩展 | 边际收益有限 | 时间够再上 |

**建议：直接做到 R3。** R2 到 R3 是性价比最高的一步，主要提升引用准确率。

## 四、工具选型

| 环节 | 首选 | 备选 | 说明 |
| --- | --- | --- | --- |
| 框架 | **LlamaIndex** | LangChain / 不用框架手写 | LlamaIndex 的索引与检索组件更直接；几千块文本时手写也够 |
| 向量库 | **Chroma** | FAISS / Milvus Lite / pgvector | 十万级 chunk 以内 Chroma 足够，零配置 |
| Embedding | **BAAI/bge-m3** | BAAI/bge-large-zh-v1.5；moka-ai/m3e-base | bge-m3 支持 8192 长文本，中文医学术语表现稳定 |
| 关键词检索 | **rank_bm25 + jieba** | Elasticsearch | 语料不大时内存里就能跑 |
| 重排 | **BAAI/bge-reranker-v2-m3** | BAAI/bge-reranker-large | 交叉编码器，对 top50 重排取 top5 |
| 切分 | 自己写标题正则 | LlamaIndex SentenceSplitter | 医学文档结构明确，正则更可控 |
| 检索评测 | **C-MTEB/CmedqaRetrieval** | 自建测试集 | 现成的中文医学检索评测集 |

模型与数据集下载：HuggingFace 或 ModelScope。国内网络优先 ModelScope，速度稳定。

## 六、验收标准

| 项 | 标准 |
| --- | --- |
| 命中率 | 自建 50 题测试集，Recall@5 达标并记录 |
| 可追溯 | 每条证据都能说出「哪个文件、哪一节」 |
| 拒答 | 语料外的问题返回空数组，不硬凑 |
| 可复现 | 同一问题两次检索结果一致 |
| 版本 | 语料和切分规则变更时版本号 +1 |

## 七、容易出问题的地方

| 问题 | 处理 |
| --- | --- |
| 按固定字数切，句子被切断 | 改按标题层级切 |
| 检索结果不相关 | 加 BM25 关键词检索，再做重排 |
| 出处丢失 | 切分时就写入元数据，不要事后补 |
| 语料来源说不清 | 入库时立刻登记 sources.md |
