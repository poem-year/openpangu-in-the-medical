## 十、下一步建议（结构化对齐）

1. **定本体**：以 ICD-10/ICD-11 中文名 + 疾病/症状/检查/药品四类实体做归一。
2. **分块规则**：一条 chunk = 一个可独立引用的事实（诊断要点、鉴别要点、检查指征、危险信号）。
3. **元数据**：`chunk_id / text / source / section / score` 对齐接口规范，另加 `disease / evidence_level / publish_date / license`。
4. **来源分级**：政府文件与指南为一级（可作依据），综述为二级，科普与问答为三级（只做检索扩展）。
5. **验收**：用 D13 的 5 道检索题 + D03/D04/D05 抽 50 个 query 测 Recall@5。
